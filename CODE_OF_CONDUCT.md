# Code of Conduct

## Pledge

Participants in this project are expected to be respectful, assume good faith, and keep discussion technical.

## Standards

- Be precise about detector limits. Do not overclaim.
- Do not share secrets, API keys, or other people's private writing in issues.
- Do not request help using this tool to evade academic or legal review of work that is not yours.

## Enforcement

Unacceptable behavior may result in a warning or a ban from the issue tracker and pull requests. Report concerns to the repository owner.
