# Security

## Reporting

If you find a vulnerability in this repository, open a private GitHub security advisory or email the repository owner. Do not file a public issue for exploitable bugs.

## Scope

This project is a local CLI and library. It does not store user text. Treat API keys in `.env` as secrets. Never commit `.env`.

## Dependencies

Optional extras download third-party model weights. Review upstream licenses and hashes before using them in a production setting.

## Out of scope

Social-engineering a commercial detector vendor, scraping a detector in violation of its terms, or using this tool to submit misrepresented academic work.
